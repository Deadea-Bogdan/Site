Despre Geo Quiz

Geo Quiz este un proiect educațional realizat pentru exersarea cunoștințelor de geografie prin teste simple, interactive și ușor de utilizat.

Ce este Geo Quiz

Geo Quiz este un site web destinat testării cunoștințelor de geografie. Utilizatorul poate parcurge diferite tipuri de teste, precum cele despre steaguri, capitale, continente sau granițe.

Scopul proiectului este de a oferi o metodă simplă și accesibilă de învățare, potrivită pentru elevi, studenți sau orice persoană interesată de geografie.
